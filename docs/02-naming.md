# Decisión de nombre

## Ganador: Exocortex

Término real (transhumanismo / ciencia ficción) para una extensión externa del cerebro que almacena y procesa información por ti — describe literalmente lo que hace el proyecto.

Verificado: existió una empresa de software 3D/VFX llamada Exocortex Technologies (Ottawa), pero está inactiva desde hace años; su producto se transformó en Clara.io y fue adquirido por Autodesk en 2017. Riesgo de colisión bajo para uso personal.

## Nombres descartados y por qué

| Nombre | Motivo de descarte |
|---|---|
| Cortex | Colisión directa: [cortex.io](https://cortex.io) es un Internal Developer Portal comercial establecido, mismo concepto (catálogo, docs, ownership) pero para equipos grandes. |
| Synapse | Colisión directa: es el servidor de referencia del protocolo Matrix (chat federado open source), muy conocido en el mundo self-hosted/dev. |
| Nexus | Demasiado genérico — usado por decenas de productos no relacionados (gestión de proyectos, apps de IA personal, gestión de emergencias). Viable pero sin identidad propia. |
| Mindex | `mindex.com` ya es una empresa de software establecida desde 1994 (Rochester, NY). Además usado por varias librerías open source pequeñas (JS, C, Filecoin). |
| Mentat | Peor que Mindex: colisiona con una herramienta de código abierto que literalmente es un asistente de código vía CLI (mismo público, mismo tipo de herramienta), más una base de datos embebida en Rust, más una app de salud mental, más una firma de IA/blockchain. |
| Ledger | Colisión fuerte e inequívoca: marca de Ledger (wallets de hardware para crypto), con su propio ecosistema de dev tools. |
| Almanac | Colisión real: producto comercial activo, wiki/herramienta de colaboración para documentos — pisa directamente la funcionalidad de documentación de Exocortex. |
| Noggin | Libre en el espacio de dev tools, pero es una marca infantil muy reconocida (Nickelodeon/Paramount). Ruido de marca sin necesidad. |
| Grimoire | Sin dueño comercial dominante, pero ya usado por varios proyectos pequeños de open source en GitHub (bookmark manager, herramientas de TTRPG, explorador de Nostr). Segunda opción viable si Exocortex dejara de servir. |
